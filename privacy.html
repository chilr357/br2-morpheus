Privacy Policy

Effective: October 26, 2026

BR2 Morpheus ("the app") is a private automation tool operated by Chilr Productions. It is used only by the channel owner to manage the owner's own YouTube channel.

What the app accesses

With the owner's authorization, the app uses the YouTube Data API (scopes youtube and youtube.force-ssl) to create and manage the channel's live broadcasts and streams, read their status, and post or read messages in the channel's own live chats.

What is collected and stored

The app stores the owner's OAuth tokens on the owner's own computer. It stores technical logs about the channel's broadcasts (video ids, titles, timestamps, stream health) and public live-chat messages that viewers post in the channel's chat, used only to count votes for the next fight. No personal data is sold, shared with third parties, or used for advertising. The app has no user accounts and does not collect data from anyone other than the public chat messages described above.

Data deletion

Stored logs are kept on the owner's equipment and can be deleted at any time. The owner can revoke the app's access at myaccount.google.com/permissions.

Google API Services User Data Policy

BR2 Morpheus' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
